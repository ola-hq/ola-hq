UPDATE POLICY

Check back here. Update when you choose.

The website is the canonical external install and update doorway. A local Operator is a versioned snapshot in your own Drive.

Nothing silently rewrites your system. If you want to update an installed Operator, tell your AI: “Update my AIOS.”

v0.3.1 · 2026-10-06

Access + Session Hygiene Patch

Login/logout guidance is now embedded in the Operator and public AIOS documentation.

AIOS does not run its own account system. Authentication happens through the AI product and the Google account/Drive connection the user chooses.

Before writes, the Operator verifies the intended Drive/account. After switching accounts, it checks again.

On shared or public devices, users should sign out of both the AI product and Google account / disconnect Drive when finished. Logging out does not delete the Operator; its files remain passive in Drive.

AIOS logs meaningful project state, receipts, and verification — not a granular surveillance-style activity trail — and it never stores passwords, one-time codes, API keys, OAuth/session tokens, cookies, or recovery codes.

v0.3 · 2026-10-06

Thread Integrity + Fidelity Patch

Threads, not copies. Ongoing projects now keep a canonical project node that points back to the real project record and source files instead of duplicating them inside AIOS.

The Hourglass route is now:

Current State → Project Registry → Project Record → Source / Reference → Rich Work → Verify → Receipt → Same Thread.

References now keep explicit roles such as style donor, photo donor, fact source, layout reference, and DO NOT INHERIT.

Critical relational instructions — “designed like this,” “use this only for the photo,” “same thing except…” — are preserved as Exact Intent Anchors when paraphrasing could change execution.

Before reference-dependent work, the Operator should reopen the relevant source when accessible instead of relying only on a compressed adjective summary.

WHY THIS PATCH EXISTS

A real continuity test broke.

A memorial-poster project preserved the subject and basic constraints but compressed a concrete visual instruction into a vague emotional summary. The next worker found the project but inherited the wrong design logic.

That exposed the missing layer: compression must preserve not only what a reference is, but what job it has.

The patch changes the architecture rather than papering over one project.

DISTRIBUTION

One doorway now.

New external AIOS installs should come through this public website. Person-specific shared installer seed documents are retired as a distribution method.

This keeps the install path current and makes version/update behavior visible in one place.
