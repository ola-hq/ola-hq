# Cinema desktop trackpad — November 27, 2026 (64)

Owner requested two-finger Mac desktop movement to hold and move the card inside the published cinema room. This Cinema-only adapter adds direct trackpad panning and pinch zoom while the immersive viewer is open. It leaves the shared gesture engine, room geometry, Cinema audio, ratings/art/Stats, Polaroid and HQ untouched.

Desktop browsers report trackpad translation as wheel input rather than finger touch positions. Pixel/line/page units are normalized. Two-finger slides move the card with content-scroll direction; card position persists after the event stream ends. Translation is bounded to keep its center recoverable. Ctrl-wheel pinch uses existing 1–3 card zoom with pan preserved; Safari gesture events apply cumulative scale/rotation once and suppress duplicate pinch-wheel updates. Input is direct rather than a synthetic touch/throw gesture; it never automatically browses, tosses or dismisses. Mouse-wheel input over the desktop stage also pans because wheel events do not reliably identify the originating device or finger count.

Handling is scoped to an open, visible fine-pointer/hover stage and ignores controls/forms, native pointer-owned gestures and card transitions. Phone touch behavior remains with the existing engine. Direct manipulation disables transform easing only during active input. Idle, pointer takeover, reset, toss, dismiss, close, visibility loss, blur and destroy cancel the transient session without moving the resting card. Destroy removes all owned listeners/timers. No shared-file or sound changes are needed.

References: https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event ; https://developer.mozilla.org/en-US/docs/Web/API/WheelEvent/deltaMode ; https://developer.apple.com/documentation/webkitjs/gestureevent . These describe event delivery, not physical device acceptance of this implementation.
